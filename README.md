# 🎀 Nikki 游戏合集

以家里八只猫为主角的浏览器游戏合集——十款自研游戏体验（九款游戏 + 一部可交互艺术长卷）加三款外链新作。**纯原生 HTML/CSS/JS，零依赖、零构建**，打开网页即玩，手机竖屏与桌面端均已适配。

**🎮 开始游玩**：<https://bayshier.github.io/Nikki/>

## 🧮 多巴算术祭（新增）

每解一道算术题，画面演出与背景音乐就**逐层升级**的算术祭典：

- **多巴值**对数攀升（1 → 2 → 4 → 8 … 直到亿），突破 100/1000/1万/…/1亿 有专属庆典
- 连击倍率：10 连击 ×1.5、20 连击 **×2 MAX**；答错不清势头、没有 Game Over
- 分层配乐：Web Audio 实时合成的马林巴进行曲，鼓组 → 低音 → 和弦 → 旋律随演出强度逐层进入，BPM 与调性随关卡推进上扬
- 一~六年级五档题库（10 以内 → 表内乘除 → 多位数 → 小数 → 两步混合）
- 基本关 10 题完走得 100 分；首答正确率 ≥80% 解锁**限时加时赛**，每题 10+5k 分往上狂飙

- **十个时代**:岩洞 → 埃及 → 浮世绘 → 莫奈 → 梵高 → 克里姆特 → 包豪斯 → 8-bit → 蒸汽波 → 新海诚;跨过画框边界时,世界和猫的画风一起切换
- **真迹入卷**:埃及、浮世绘、梵高三幕采用大都会博物馆开放访问的公有领域真迹——北斋《神奈川冲浪里》原版画、梵高《麦田与柏树》(Met 49.30)、Menna 墓狩猎图摹本;代码负责让真迹"活起来":浪爪锚定真迹浪峰爬行、梵高的笔触在呼吸、墓室里的火把光在晃
- **画面工艺**:全片胶片颗粒+暗角、远景雾化的三层空气感、每时代专属纹理(纸纤维/画布织纹/金箔/VHS 噪声);时代字卡衬线金边,支持时代直达、快进、静音与"📷 拍下来"
- **零素材依赖**:除三幅真迹照片外全部代码绘制,未使用任何位图素材

开发小记:这部长卷经历了三版——v1 手绘全场景被吐槽"抽象",v2 补齐颗粒/层次/密度/造型四门工艺课,v3 想明白了"精美"的正解是**站在真艺术品肩膀上做动效**,于是把公有领域名画直接请进长卷。生成式出图(内网 qwen-image 两模型)本想补齐剩余四幕,因中转渠道权限全部 403 暂时搁置,待渠道恢复再补。

## 🏗 技术特点

- **零依赖零构建**：每个游戏都是独立静态页面，克隆即用
- **公共系统层** `shared/common.js`（约 113 行）：
  - 💰 **统一钱包**——金币跨游戏通用，老存档自动迁移
  - 📅 **每日挑战**——日期哈希抽签，当天全员同一任务，达标自动发金币
  - 🐱 **猫咪图鉴**——跨游戏成就规则表，解锁进度全端共享
- **音效全合成**：Web Audio API 振荡器现场生成，零音频文件
- **存档全部本地**（localStorage），不采集、不上传任何数据
