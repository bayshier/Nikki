# 🎀 Nikki 游戏合集

以家里八只猫为主角的浏览器游戏合集——十六款自研小游戏与 3D 世界（外加一部可交互艺术长卷和一个算术练习），再加三款外链新作。**纯原生 HTML/CSS/JS，零依赖、零构建**，打开网页即玩，手机竖屏与桌面端均已适配。

**🎮 开始游玩**：<https://bayshier.github.io/Nikki/>（会跳转到自定义域名 nikki.us.ci；该域名的 HTTPS 证书还在等 DNS 补齐两条 A 记录，见下方「域名备忘」）

## 🧮 多巴算术祭（新增）

每解一道算术题，画面演出与背景音乐就**逐层升级**的算术祭典：

- **多巴值**对数攀升（1 → 2 → 4 → 8 … 直到亿），突破 100/1000/1万/…/1亿 有专属庆典
- 连击倍率：10 连击 ×1.5、20 连击 **×2 MAX**；答错不清势头、没有 Game Over
- 分层配乐：Web Audio 实时合成的马林巴进行曲，鼓组 → 低音 → 和弦 → 旋律随演出强度逐层进入，BPM 与调性随关卡推进上扬
- 一~六年级五档题库（10 以内 → 表内乘除 → 多位数 → 小数 → 两步混合）
- 基本关 10 题完走得 100 分；首答正确率 ≥80% 解锁**限时加时赛**，每题 10+5k 分往上狂飙

### 2026-10-27 · 手感与帧率正确性:游戏开发技能审查清单落地

用 [awesome-gamedev-agent-skills](https://github.com/gamedev-skills/awesome-gamedev-agent-skills)(76 个游戏开发 agent 技能)当审查清单,把 game-feel / performance-optimization / physics-tuning / platformer 等技能的标准逐项过了一遍全仓库,相关技能已装进本机全局技能目录供后续开发复用:

- **帧率正确性修复**(physics-tuning「固定时间步」):飞飞猫 / 打砖块 / 高尔夫 / 弹幕 / 守塔 / 高尔夫 3D 原来是裸 `requestAnimationFrame` 按渲染帧跑逻辑,在 144Hz 高刷屏上整个游戏等比加速 2.4 倍;现在统一走 `Nikki.Feel.play` 的 60Hz 固定步长驱动(马里奥 / 俄罗斯方块 / 猫岛本来就是固定步长,顺手表扬),切后台回来不追帧不爆炸
- **公共手感层 `Nikki.Feel`**(game-feel):hit-stop 顿帧(命中瞬间冻结逻辑、画面照常渲染)+ trauma 屏震(受击叠加、平方衰减、正弦驱动不抖动感);接进五个游戏的死亡 / 击杀 / 落水 / 突破瞬间
- **马里奥补齐跳跃手感三件套**(platformer):土狼时间 0.10s + 跳跃缓冲 0.12s(变重力收跳、起跳拉长落地压扁原本就有)
- **高尔夫 3D 相机**(camera-systems):镜头跟随从每帧 `lerp(0.06)` 改为帧率无关的指数平滑,云 / 水纹动画按真实 dt 缩放
- **存档版本化**(save-systems):`common.js` 的读写打上 `{v:1}` schema 包裹,读取新旧格式都认,以后字段升级可走迁移链不踢老存档
- 全流程本地实测:七个改动页面加载 / 开局 / 死亡 / 进洞零报错,`__golf3d.step()` 确定性钩子跑通一杆进洞

## 🏗 技术特点

- **零依赖零构建**：每个游戏都是独立静态页面，克隆即用
- **公共系统层** `shared/common.js`（约 113 行）：
  - 💰 **统一钱包**——金币跨游戏通用，老存档自动迁移
  - 📅 **每日挑战**——日期哈希抽签，当天全员同一任务，达标自动发金币
  - 🐱 **猫咪图鉴**——跨游戏成就规则表，解锁进度全端共享
- **音效全合成**：Web Audio API 振荡器现场生成，零音频文件
- **存档全部本地**（localStorage），不采集、不上传任何数据

## 🌐 域名备忘

自定义域名 `nikki.us.ci` 已绑定 GitHub Pages(仓库根目录的 `CNAME`),但截至 2026-11-25 **只能明文 HTTP 访问**:
`http://nikki.us.ci` 正常,`https://nikki.us.ci` 返回的是 GitHub 默认的 `*.github.io` 证书,浏览器会报证书错误。

- **原因**:根域名只配了两条 A 记录(`185.199.108.153`、`185.199.109.153`),GitHub 给根域名签发证书要求四条齐全。
- **待办**(需要登录域名服务商的面板,代码仓库里做不了):
  1. 补两条 A 记录:`185.199.110.153`、`185.199.111.153`;
  2. 等 GitHub 自动签发证书(几分钟到 24 小时不等);`gh api repos/bayshier/Nikki/pages` 的返回里出现 `certs` 就是成功了;
  3. 证书到位后再开强制 HTTPS:`gh api -X PUT repos/bayshier/Nikki/pages -f cname=nikki.us.ci -F https_enforced=true`
     (证书没签下来之前千万别开,否则整站会被重定向到报错的 HTTPS);
  4. 可选:加 `www` 的 CNAME 指向 `bayshier.github.io`。
- 在此之前,对外的地址一律用 `https://bayshier.github.io/Nikki/`(它会跳到 `http://nikki.us.ci`)。
