## 🧮 多巴算术祭（新增）

每解一道算术题，画面演出与背景音乐就**逐层升级**的算术祭典：

- **多巴值**对数攀升（1 → 2 → 4 → 8 … 直到亿），突破 100/1000/1万/…/1亿 有专属庆典
- 连击倍率：10 连击 ×1.5、20 连击 **×2 MAX**；答错不清势头、没有 Game Over
- 分层配乐：Web Audio 实时合成的马林巴进行曲，鼓组 → 低音 → 和弦 → 旋律随演出强度逐层进入，BPM 与调性随关卡推进上扬
- 一~六年级五档题库（10 以内 → 表内乘除 → 多位数 → 小数 → 两步混合）
- 基本关 10 题完走得 100 分；首答正确率 ≥80% 解锁**限时加时赛**，每题 10+5k 分往上狂飙

## 🏗 技术特点

- **零依赖零构建**：每个游戏都是独立静态页面，克隆即用
- **公共系统层** `shared/common.js`（约 113 行）：
  - 💰 **统一钱包**——金币跨游戏通用，老存档自动迁移
  - 📅 **每日挑战**——日期哈希抽签，当天全员同一任务，达标自动发金币
  - 🐱 **猫咪图鉴**——跨游戏成就规则表，解锁进度全端共享
- **音效全合成**：Web Audio API 振荡器现场生成，零音频文件
- **存档全部本地**（localStorage），不采集、不上传任何数据
