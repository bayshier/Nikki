# 🐱 猫咪素材说明

把 8 只猫咪的头像图片放到**本文件夹**(`assets/cats/`),文件名必须**严格对应**下表(小写拼音):

| 猫咪名字 | 文件名(必须完全一致) |
|---------|----------------------|
| 陈皮    | `chenpi.jpg`         |
| 包子    | `baozi.jpg`          |
| 年年    | `niannian.jpg`       |
| 松露    | `songlu.jpg`         |
| 大儿    | `daer.jpg`           |
| 警长    | `jingzhang.jpg`      |
| 有鱼    | `youyu.jpg`          |
| 阿狸    | `ali.jpg`            |

## 要求
- **格式**:`.jpg`(也支持 `.png`/`.webp`,见下方"想用其他格式")
- **尺寸**:建议 **正方形**,推荐 200×200 ~ 400×400 像素
- **内容**:猫咪头像/脸部特写,清晰为主
- **大小**:单张建议 < 200KB(加载快)

## 想用其他格式
如果想用 `.png`,把 `index.html` 里 8 处 `.jpg` 改成 `.png` 即可
(搜索 `assets/cats/` 一次性替换)。

## 还没放图会怎样?
代码内置了**图片加载失败的兜底**:某只猫的图片没放或路径错,
会自动显示**彩色圆圈 + 猫咪名字**(陈皮/包子/…),游戏照常运行。
所以你可以先玩,边玩边补图!
