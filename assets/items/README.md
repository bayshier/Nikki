# 🎨 道具图制作规格说明

把做好的道具图放进**本文件夹**(`assets/items/`),文件名按下面表格命名(全小写)。
图放进来**刷新页面即自动生效**——鼠标光标和未来扩展的界面会自动用上,不用改代码!

## 📐 统一规格

| 项目 | 要求 |
|------|------|
| **尺寸** | **256 × 256 px**(正方形,一张图两用:道具栏图标 + 鼠标光标) |
| **格式** | `.png` **透明背景** |
| **主体** | 画面主体居中,占画布约 **80%**(四周留边,光标缩到 40px 时依然清晰) |
| **风格** | 可爱卡通、描边清晰、颜色鲜艳(和游戏粉色系搭) |
| **大小** | 单张 < 100KB |
| **作用点** | 光标使用时"点击有效位置"= 图片正中心,重要部分别偏到角落 |

## ⚡ 生效机制

- 光标:进入道具瞄准模式时,鼠标变成对应道具图(代码已按上面的文件名自动加载)
- 图片缺失时自动用 emoji 占位,所以**可以一张一张慢慢补**
- 命名必须完全一致(全小写),放错名字的图不会生效
